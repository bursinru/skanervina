## Обновление: одна карточка, диагностика, CPU и выделение

См. [актуальный отчёт](../reports/recognition/README.md). Текущий API возвращает одну карточку и при uncertain, но eval/predict продолжает возвращать null для таких случаев. Панель администратора требует SCANNER_ADMIN_TOKEN. В интерфейсе путь: исходное фото → автоматическое выделение этикетки на backend → поиск → одна карточка с предупреждением о сходстве. Нет утверждения о правильности выбора вина на реальном снимке без ground truth.
