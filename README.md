# Своё Вино — отдельная страница сканера

Первая итерация мобильного интерфейса. Node.js 20+, без установки зависимостей.

```sh
npm run dev
# http://localhost:4173/scanner
npm run build
npm run preview
```

## Реализовано

- Страница `/scanner`, адаптивная для телефона и компьютера.
- Камера с задним объективом, снимок, остановка камеры при уходе со страницы.
- Загрузка / drag-and-drop JPG, PNG, WebP до 15 МБ, проверка декодирования.
- Предпросмотр, замена фотографии, состояния поиска, отмены и ошибки.
- Явно обозначенный пример карточки из предоставленного каталога: Фанагория Blanc de Blancs.
- Подбор блюда по правилам для стиля примера, личная оценка вина и сохранение в этом браузере.
- Пустые состояния вместо выдуманных рейтингов и рыночных цен.

## Граница текущей итерации

CV-распознавание ещё не реализовано. При пустом `recognitionEndpoint` фотографии никуда не отправляются: интерфейс сообщает об отсутствии подключения. Кнопка примера открывает заранее выбранную карточку и не имитирует распознавание загруженного снимка.

Настройка URL — `public/config.js`. Production-сервис должен использовать HTTPS и разрешать CORS только для нужного фронтенда. Для камеры браузеру нужен HTTPS или localhost. Шрифты загружаются с Google Fonts; при недоступности используется системный шрифт.

Продуктовый API принимает `POST multipart/form-data`, поле `image`. Ответ:

```json
{
  "status": "matched",
  "slug": "wine-slug",
  "wine": {
    "name": "Название",
    "winery": "Винодельня",
    "category": "Белое сухое",
    "color": "Белое",
    "region": "Кубань",
    "grapes": ["Шардоне"],
    "public_rating": 4.6,
    "temperature": "10-12°C",
    "alcohol": "11%",
    "dishes": ["Морепродукты", "Сыры"],
    "region_image_url": "https://api.vino-svoe.ru/.../krym.webp",
    "grape_image_url": "https://api.vino-svoe.ru/.../Malvaziya.webp",
    "dish_image_urls": ["https://api.vino-svoe.ru/.../ptica.webp"],
    "image_url": "https://example.org/wine.webp",
    "description": "Описание из каталога",
    "source": "Источник описания"
  }
}
```

`unknown` / `uncertain` предлагают переснять фото. Плоский ответ конкурсного endpoint `{"slug":"..."}` требует отдельного получения карточки и не является контрактом этого UI. Таймаут — 30 секунд, отмена через AbortController.

## Данные

Описание примера и фотография взяты из предоставленного датасета. Краткое описание и ароматы основаны на тексте каталога. Изображения региона, сорта и гастросочетаний берутся из публичного CDN «Своё Вино»; если для конкретного названия ещё нет URL, карточка показывает текстовый вариант. Рекомендации к блюдам — общие правила для белого игристого брюта, помеченные в UI. Год и магазинные цены не выдумываются; публичный рейтинг и характеристики реального результата берутся из обогащённого каталога с сохранённым URL источника.

`public/assets/blanc-de-blancs.webp` соответствует исходному файлу `fanagoriya_blanc_de_blancs_shardone_igristoe_bryut_beloe_12_4071ae25d5.webp`.

## Сборка и перенос

`npm run build` создаёт только публичные файлы в `dist`; тяжёлый каталог `Датасет/` исключён из Git через `.gitignore`. `vercel.json` подготовлен для статической публикации. На другом сервере достаточно раздавать `dist`, включая `dist/scanner/index.html`.

## GitHub и Vercel

В репозиторий нужно добавлять исходники сайта, но не каталог `Датасет/` с выгруженными изображениями и CSV. `.vercelignore` дополнительно исключает датасет и backend из фронтенд-upload при деплое через Vercel CLI. Файл `.env.example` содержит переменные, которые можно задать в настройках Vercel:

- `SCANNER_RECOGNITION_ENDPOINT` — HTTPS endpoint распознавания; пустое значение оставляет демо-режим.
- `SCANNER_IMAGE_BASE_URL` — базовый URL изображений каталога. По умолчанию используется формат `api.vino-svoe.ru` вида `.../uploads/<имя-файла>`.

Сборка Vercel выполняется командой `npm run build`, а результатом является каталог `dist`. Когда проект будет перенесён на `vino-svoe.ru`, код менять не потребуется: достаточно заменить домен в настройках Vercel и при необходимости оставить тот же `SCANNER_IMAGE_BASE_URL`. Карточки результатов уже принимают полные HTTPS-ссылки на изображения, а также имена файлов каталога.

## Backend MVP

Первый backend находится в `backend/`. Он принимает `POST /v1/recognize`, проверяет изображение, выполняет OCR и ищет вино в CSV-каталоге. Инструкция запуска и Docker-конфигурация находятся в [`backend/README.md`](backend/README.md). Backend разворачивается отдельно от Vercel-фронтенда; сам датасет подключается снаружи и не входит в репозиторий.

## Обогащение каталога

[`scripts/enrich_vino_svoe.py`](scripts/enrich_vino_svoe.py) читает публичный каталог `vino-svoe.ru/wines` и создаёт `Датасет/strapi_output0709_enriched.csv`, не изменяя исходный CSV. В новые поля попадают URL карточки, народный рейтинг, регион, сорта, категория, цвет, изображения региона и сорта, температура подачи, крепость, гастросочетания, изображения блюд, описание и URL бутылки. Каждый ряд получает `svoe_vino_scraped_at` и статус загрузки.

Для запуска scraper нужны Python 3.9+ и `beautifulsoup4`:

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/enrich_vino_svoe.py
```

Скрипт делает запросы с ограниченной параллельностью и задержкой. Исходные данные, enriched CSV и отчёт остаются локальными и исключены из Git. Числовой рейтинг Роскачества не добавляется, если сайт не отдаёт его в публичной карточке: он не подменяется народным рейтингом.
